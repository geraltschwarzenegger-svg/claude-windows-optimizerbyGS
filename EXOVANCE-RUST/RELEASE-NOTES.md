Exovance Rust 0.1.1 Preview

- Исправлено определение ветки GPU: присутствующий PCI-адаптер → Driver → CurrentControlSet; выбор при нескольких GPU и отказ от неподтверждённых путей.
- Сохранены значения GPU-пресетов, NVIDIA-профиль, назначения IRQ/RSS и поведение Unlimited.
- Исправлена проверка встроенного движка при наличии старого кэша Cargo.
- Версия в интерфейсе, --version и BUILD-INFO берётся из Cargo.toml.

Скачайте Exovance-Rust-Windows-x64.zip из Assets и распакуйте в отдельную папку. Внутри сразу находятся Exovance.exe, ресурсы и лицензии; повторно распаковывать ZIP не требуется. Для проверки целостности рядом опубликован SHA256.

Сборка выполнена на Windows с MSVC. Проверены изолированные PowerShell/Rust-тесты, pipe-транспорт Windows PowerShell 5.1 и режимы просмотра/проверки EXE. Изменения оборудования и прирост производительности не проверялись.

Это предварительная версия и частичный перенос на Rust: интерфейс и управление схемами питания нативные; остальные операции используют встроенный PowerShell 5.1 и комплектные внешние программы.
