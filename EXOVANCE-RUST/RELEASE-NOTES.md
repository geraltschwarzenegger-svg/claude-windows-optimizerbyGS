Exovance Rust 0.1.2 Preview

- Добавлена нативная диагностика `--diagnose`: JSON-отчёт о комплектных ресурсах и схемах электропитания.
- Добавлен безопасный экспорт `--diagnose-output` в новый JSON-файл без перезаписи существующих файлов.
- Проверки `powercfg /list` и `powercfg /getactivescheme` выполняются только для чтения. Реестр, службы, драйверы и настройки не изменяются.
- Исправлена проверка генерируемого PowerShell backend в `Test-Bridge.ps1` для Windows/Linux CI.
- Существующие функции CMD, GPU-профили и пресеты не менялись.

Это предварительная версия с частичным переносом на Rust: интерфейс и управление схемами питания работают на Rust; другие функции используют встроенный Windows PowerShell 5.1.

Скачайте `Exovance-Rust-Windows-x64.zip` в GitHub Releases или из корня репозитория после успешной публикации. ZIP в корне создаётся автоматическим workflow из того же релизного архива; отдельной ручной замены binary не требуется. В архиве `Exovance.exe`, ресурсы и уведомления о лицензиях, распаковка в отдельную папку.

Сборка и изолированные тесты не доказывают улучшение FPS, DPC, задержки ввода или совместимость всех твиков с конкретным ПК. Не проверено на физическом оборудовании пользователя.
