# NVIDIA Profile Inspector Revamped для меню v2

В комплект включён официальный portable-релиз [NVPI-R 7.3.2.0](https://github.com/xHybred/NvidiaProfileInspectorRevamped/releases/tag/v7.3.2.0):
`NVPI-R.exe`, `NVPI-R.exe.config`, `CustomSettingNames.xml`, `Reference.xml`.
Имена и содержимое этих четырёх файлов сохранены из архива. Дополнительные REG-файлы и профиль Hybred из архива не подключены.

- Источник: https://github.com/xHybred/NvidiaProfileInspectorRevamped/releases/download/v7.3.2.0/NVPI-R.zip
- Соответствующий исходный код релиза: `d593b2fe3e77119036355875acaa3a761bc917de`.
- SHA256 скачанного архива: `febb6e1dda9b420e918aeb54deaf176612a5f2371b0287079bd58a5103757d47`.
- Лицензия: MIT, см. `LICENSE-NVPI-R.txt`; описание автора — `UPSTREAM-ReadMe.txt`.
- Контрольные суммы включённых файлов: `../../SHA256SUMS.txt`. Это фиксация полученных файлов, а не независимая подпись автора.

## Запуск и импорт

В меню v2: **Apps → NVIDIA Profile Inspector Revamped**.

- **Launch NVPI-R** открывает интерфейс без импорта профиля.
- **Import NvidiaV2.nip (global / Merge)** запускает `NVPI-R.exe -mergeImport "полный путь к NvidiaV2.nip"` и ждёт завершения процесса.
- Auto Registry Tweaks использует этот же импорт при обнаружении NVIDIA (включая смешанную конфигурацию); при другой/неизвестной GPU пропускает его.

Требования NVPI-R: Windows 10/11 x64, .NET Framework 4.8, совместимый драйвер NVIDIA, права администратора. Для самого меню v2 по-прежнему нужен Windows PowerShell 5.1 x64.

Импорт использует Merge: меняет перечисленные в файле значения и сохраняет остальные. Это не резервная копия и не откат. Перед импортом можно экспортировать текущий профиль через интерфейс NVPI-R.
Результат показывает диалог NVPI-R. Silent-режим намеренно не используется: он скрывает отчёт о частичных ошибках. В 7.3.2.0 ошибки импорта могут сопровождаться кодом выхода 0, а запрос — передаваться уже работающему экземпляру. Поэтому меню не объявляет импорт подтверждённым: после завершения процесса выводится предупреждение; Auto учитывает этот шаг как warning. Проверьте диалог и перечитайте настройки в NVPI-R.

## Пользовательский NvidiaV2.nip

Это предоставленный пользователем **глобальный** профиль с 43 настройками; отсутствие `ProfileName` трактуется NVPI-R как текущий глобальный профиль. Значения сохранены. Исправлена только декларация XML: исходный файл имеет UTF-8 BOM, но заявлял UTF-16; теперь указан UTF-8.

В частности:

| Параметр | ID | Значение |
| --- | --- | --- |
| ReBAR — Enable v2 | `0x000BFA21` | `2` = Enabled |
| ReBAR — Enable | `0x000F00BA` | `1` = Enabled |
| ReBAR — Size Limit | `0x000F00FF` | `2147483648` = 2 GiB, Qword |

В поставляемом `CustomSettingNames.xml` для Enable v2 указан минимальный драйвер **616.56**. На более старом драйвере действие нового параметра не подтверждено. Профиль не включает поддержку ReBAR в BIOS/UEFI или VBIOS и не проверяет её. Убедитесь, что NVIDIA сообщает о включённом Resizable BAR в сведениях о системе.

Профиль также отключает G-SYNC/VRR, задаёт фильтрацию, кэш шейдеров, режим питания и другие параметры. Это не универсальный профиль только для ReBAR. Enabled и лимит 2 GiB не гарантируют прибавку FPS: результат нужно сравнивать в конкретных играх; при ухудшении используйте рекомендованный драйвером Auto или отдельный игровой профиль.

Linux-проверки подтверждают XML, выбор ресурсов, аргументы процесса, GPU-dispatch и обработку ошибок со stub-процессом. Windows GUI, запись NVAPI и производительность здесь не проверены.
