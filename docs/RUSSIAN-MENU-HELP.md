# Русская справка меню Exovance v2

## Управление

- Стрелки выбирают строку. Нижняя панель поясняет назначение, эффект выбранного действия, место изменения и рекомендацию.
- Enter в меню открывает подменю или запускает действие.
- F1 открывает справку. Она не читает текущий реестр и не применяет настройки.
- PgUp/PgDn и стрелки листают длинную справку; Home/End переходят к началу/концу.
- Enter, Esc и F1 в справке закрывают её. Выбранный пункт сохраняется, применение требует отдельного Enter в меню.
- В маленьком окне показывается краткая панель; F1 содержит полное описание. Строки с `… [F1]` сокращены только в нижней панели.

## Что показывается

Назначение функции и результат Enable/Disable объясняются отдельно. Например, HAGS Enable записывает `HwSchMode=2`, Disable — `HwSchMode=1` в `HKLM\SYSTEM\CurrentControlSet\Control\GraphicsDrivers`. Список «Будет записано» строится из тех же таблиц, которые использует действие, с именем параметра, значением и типом. Это не отчёт о текущем значении Windows.

Для UAC, FSO, Game Bar/Game Mode, MMCSS, служб, Win32PrioritySeparation, Clock Interrupts и пресетов GPU отображаются соответствующие таблицы при выборе действия. Для сети и QOL описаны динамические ветки и дополнительные механизмы: состав зависит от адаптеров/профилей. Для файлов .pow, профилей NVIDIA и внешних утилит честно указан запуск через powercfg, NVAPI или отдельный файл. Единого заранее известного ключа реестра у таких действий нет.

В списке автозапуска F1 показывает доступные поля источника выбранной записи: RegistryPath, Location, TaskPath, Command и другие. Открытие справки не переключает запись.

## Как понимать рекомендации

- UAC: для обычного использования — Enable.
- Game Mode: обычно Enable; при воспроизводимой проблеме сравнивать отдельно.
- Game Bar: разрешать захват, если нужна запись; пресет Enable разрешает также фоновый захват.
- FSO: начать с Enable; Disable проверять для конкретной проблемной игры.
- HAGS: сравнивать на своём GPU/драйвере; учитывать требования Frame Generation.
- MMCSS: оставить включённым; звуковые пресеты проверять при реальных проблемах звука.
- Службы, сеть, Win32PrioritySeparation и таймерный пресет: применять под конкретную задачу с сохранением исходных настроек.
- Автозапуск: отключать узнаваемые ненужные программы по одной.

Это рекомендации для ручного выбора. Существующий Auto остаётся готовым пресетом со своим составом: в частности, включает HAGS и отключает FSO/Game Bar/Game Mode/UAC. Справка перечисляет это явно. Рекомендации не переписывают Auto, реестровые значения, IRQ/MSI/RSS или поведение Unlimited в отдельном Device Tweaker.

## Кодировка и проверки

CMD сохранён в UTF-8 без BOM с CRLF; при извлечении PowerShell-части явно используется `Get-Content -Encoding UTF8`. Это необходимо для кириллицы в Windows PowerShell 5.1 независимо от ANSI-кодовой страницы.

Изолированные проверки охватывают русские описания разделов/подменю, соответствие значениям таблиц, длинные пути, прокрутку и изменение размера, отсутствие команд записи в справке, отдельный маршрут F1 и запуск `/demo /snapshot` до системной инициализации. Режим `/demo` позволяет посмотреть интерфейс без применения настроек.
