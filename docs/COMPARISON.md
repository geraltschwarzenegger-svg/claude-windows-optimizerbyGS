# 🔬 Оригинал и v2

**v2 сохраняет исходные наборы настроек и добавляет проверку среды, явные подтверждения и контроль полноты загрузок по известному размеру.** Новые «ускоряющие» значения реестра не добавлялись.

## 📌 Что обнаружено при изучении

| Наблюдение в оригинале | Изменение в v2 |
| :--- | :--- |
| При открытии меню сразу выбран Auto. Enter начинает пакет, первым отключая UAC. | Первым выбран **Preflight / About v2**. Сам Auto требует точного ввода `AUTO`. |
| QOL меняет несколько профилей, отключает OneDrive, чистит историю и закрепления без отдельного подтверждения. | Отдельный QOL требует точного ввода `QOL`; масштаб изменений показан до подтверждения. |
| Отдельного диагностического запуска нет. | `/check` выполняет проверку хоста до transcript, TrustedInstaller, native initialization и меню. |
| При первом аудите в репозитории не было внешних ресурсов, хотя меню предлагало их запуск. | Preflight сообщает, найден ли каталог `Resources`; перечень ограничений добавлен в README. |
| Новые Device Tweaker и схема питания загружены в корень, а оригинал ожидает их в `Resources`. | Для этих двух файлов добавлен поиск в корне при отсутствии прежнего пути. Остальные пути не перенаправляются. |
| Загрузчик считает полученные байты, но не сверяет их с заявленным размером перед переименованием `.partial`. | Добавлен `Assert-LlcDownloadLength`: пустой файл или несовпадение известного размера вызывают ошибку до сохранения конечного файла. |

## 🧭 Сценарии запуска

| Сценарий | Оригинал | v2 |
| :--- | :--- | :--- |
| Запуск без аргументов | Административное меню | Проверка хоста, затем административное меню |
| Первый Enter в главном меню | Запуск Auto | Просмотр Preflight / About |
| Выбор Auto, затем Enter на запросе подтверждения | Нет запроса | Отмена без запуска пакета |
| Выбор Auto, затем `AUTO` | Нет запроса | Запуск исходного пакета целиком, включая QOL |
| Отдельный QOL, затем пустой ввод | Нет запроса | Отмена без применения QOL |
| `/check` | Специального режима нет | Только синтаксис и базовые требования; администратор не нужен |
| `/help` или `/?` | Специальной справки нет | Справка без запуска PowerShell |
| Неизвестный аргумент / лишний аргумент | Не обрабатывается специально | Ошибка аргументов, код `2` |
| Ошибка извлечения payload при `/check` | Специального режима нет | Код `1`, без ожидания `pause` |

Подтверждение принимает **только** точный текст `AUTO` или `QOL` для соответствующего действия. Нижний регистр, пробелы, пустой ввод, иной текст или ошибка чтения отменяют запуск. Подтверждение пакета не является созданием резервной копии.

## 🔎 Границы preflight

Проверка хоста требует Windows, Windows PowerShell Desktop версии не ниже 5.1 и 64-битный процесс. Это предварительный фильтр; совместимость конкретной сборки ОС, GPU, служб, драйверов, политик и всех реестровых параметров он не устанавливает.

`/check` завершается до запуска транскрипта и основного кода. Он не применяет настройки, не запускает внешние ресурсы и не обращается к драйверным сайтам. Launcher создаёт и удаляет временный файл payload.

Наличие каталога `Resources` — информационный результат. `/check` дополнительно показывает наличие включённых launcher Device Tweaker и схемы питания рядом с CMD. Он не проверяет существование каждого EXE/BAT/POW/NIP и не удостоверяет их подлинность. Отсутствие каталога не блокирует встроенные пункты меню и не приводит к ненулевому коду `/check` на подходящем хосте.

Для `Resources\DEVICE-TWEAKER\RUN-DEVICE-TWEAKER.bat` и `Resources\POWER-PLAN\LLC-CERTIFIED.pow` v2 сначала ищет файл по прежнему пути, затем в одноимённых папках рядом с CMD. Остальные ресурсы сохраняют исходные пути. Загруженные пользователем файлы Device Tweaker и схемы питания не изменялись; их выполнение и импорт в Windows здесь не проверялись.

## 📥 Контроль загрузки

| Полученный размер | Заявленный размер | Поведение v2 |
| :--- | :--- | :--- |
| `0` или меньше | Любой | Ошибка; конечный установщик не сохраняется |
| Положительный | Известен, не совпадает | Ошибка; `.partial` удаляется обработчиком ошибки |
| Положительный | Известен, совпадает | Загрузка может завершиться успешно |
| Положительный | Неизвестен (`-1`) | Допускается с предупреждением: полнота не подтверждена |

Контроль размера не проверяет цифровую подпись, издателя, безопасность, совместимость драйвера или его актуальность. Authenticode и контрольные суммы установщиков не добавлены. Существующие проверки HTML/content type и HTTPS сохранены.

## 🗃️ Сохранность оригинала

Исходный файл оставлен **побайтово неизменным**:

```text
Low-Latency-Corp-Menu_SPI_24H2_VisualizationFix.cmd
SHA-256: 931b36ce50635e2faaa816dabc4950999f52f35be5dbf764c703a8c32440f466
```

Новая версия хранится отдельно в `Low-Latency-Corp-Menu_v2.cmd` с окончаниями строк CRLF для Windows. Для удобного сравнения без шума от окончаний строк:

```sh
git diff --no-index --ignore-space-at-eol -- Low-Latency-Corp-Menu_SPI_24H2_VisualizationFix.cmd Low-Latency-Corp-Menu_v2.cmd
```

Для `git diff --no-index` код `1` означает, что различия найдены.

## 🧪 Что подтверждено и что осталось проверить

Автономный [tests/Test-V2.ps1](../tests/Test-V2.ps1) проверяет синтаксис payload обеих версий и новую логику без применения твиков. Проверки новых функций выполняются отдельно от приложения.

В облаке использован PowerShell 7.4.13 на Linux. Запуск диагностической ветки здесь должен завершаться кодом `2`, поскольку это неподходящая платформа для меню. Это ожидаемый отказ, а не успешный тест применения настроек.

**В Windows ещё нужны:** проверка batch-launcher (`/help`, `/check`, ошибки аргументов), Windows PowerShell 5.1, интерактивного меню, временного файла, прав администратора и выбранных действий в тестовой VM. Проверки реестра, служб, загрузок с реальных сайтов и эффекта на производительность в Linux не выполнялись.

v2 не добавляет системный бэкап, точку восстановления, полный откат или гарантированный прирост производительности. Выпуск объединяет новые пользовательские ресурсы с меню через поиск файлов, сохраняя их содержимое. Пункты Enable / Revert по-прежнему могут выставлять авторские значения вместо восстановления исходного состояния ПК.
