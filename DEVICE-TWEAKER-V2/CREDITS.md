# Происхождение и авторство

Exovance Device Tweaker v2 — производная версия исходного Device Tweaker, уже включённого в репозиторий geraltschwarzenegger-svg/claude-windows-optimizerbyGS. Это не заявление об авторстве исходного инструмента целиком.

- Исходный файл: `../DEVICE-TWEAKER/DEVICE-TWEAKER-UPDATE-2026-LLG-X-LLC-UPDATED.ps1`.
- Исходное оформление указывало **BYND_PERF / Beyond Performance**, Low Latency Gaming. Это сведения, содержащиеся в оригинале, без независимой проверки личности автора.
- Исходная база этой версии: commit `afd40645af66e92436c8503930d250953a279d9a` данного репозитория.
- Существующие алгоритмы обнаружения устройств, WinForms-интерфейс, топология, низкоуровневые PCI/NVMe/USB функции происходят из оригинала.
- Значок `Exovance.ico` создан для Exovance с помощью генерации изображения; заменяет прежний значок окна LLG.
- Изменения Exovance: новый визуальный слой Exovance, состояния выбора/выполнения и клавиатурная навигация, отдельный launcher/каталог/cache, маски UInt64, RSS-планирование и сохранение/восстановление, обработка ошибок и регрессионные проверки. Подробности — в README.md.
- Встроенный шрифт CPMONO содержит собственное уведомление об авторстве Tino Meinert; его двоичные данные и встроенное уведомление сохранены.
- Справочник `pci.ids` скопирован без изменений из оригинального каталога; его собственный заголовок сохранён.

Оригинальная папка и её исходники сохранены без изменений. Этот документ фиксирует происхождение и не заменяет условия правообладателей компонентов.
