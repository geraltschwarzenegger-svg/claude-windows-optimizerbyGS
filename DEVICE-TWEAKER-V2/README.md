# Exovance Device Tweaker v2

Отдельная версия Device Tweaker из этого репозитория. Оригинальный каталог `DEVICE-TWEAKER` сохранён без изменений. Происхождение исходного кода и встроенного шрифта указано в [CREDITS.md](CREDITS.md).

## Запуск

Нужны Windows PowerShell **5.1 x64**, интерактивный рабочий стол Windows и права администратора. PowerShell 7 не предназначен для запуска этого интерфейса.

Из корня проекта: **Low-Latency-Corp-Menu_v2.cmd → Apps → Exovance Device Tweaker v2 → Launch Exovance v2**. Пункт **Launch original Device Tweaker** открывает прежний инструмент.

Самостоятельно: нажмите правой кнопкой по `RUN-EXOVANCE-V2.bat` → «Запуск от имени администратора». Сохраняйте весь каталог v2: PS1, Exovance.Core.ps1 и pci.ids нужны рядом с launcher.

Проверка синтаксиса и базовых требований без открытия GUI и без применения настроек:

```bat
RUN-EXOVANCE-V2.bat /check
```

Код 0 означает успешную базовую проверку, 2 — неподходящую среду или ошибку. Проверка не подтверждает совместимость каждого устройства.

Версия ограничена **одной processor group, до 64 логических CPU**. Несколько групп блокируются до запуска основного кода: единая 64-битная маска не описывает CPU во всех группах.

## Кнопки

- **Apply** применяет выбранные вручную affinity, MSI, IRQ priority/policy и RSS. Для пустого выбора affinity сбрасываются маска и SpecCPU policy; для RSS требуется выбрать базовый CPU либо восстановить backup.
- **Auto Optimization** после вопросов о backup, MSI и режиме RSS/IRQ/BOTH самостоятельно применяет алгоритм автора. Отдельно нажимать Apply после Auto не требуется.
- **Alternate Plan** — прежний Secret Optimization с понятным описанием. Алгоритм группирует часть USB/audio/network устройств на общем CPU, отдельно распределяет GPU и при определённых топологиях изменяет ReservedCpuSets. Перед запуском показывается описание. HAGS эта версия не меняет.
- **Backup** сохраняет текущие настройки, поддерживаемые инструментом.
- **Reset** восстанавливает выбранный backup; это не универсальный сброс Windows к заводским значениям.

Рекламные BUY/сервисные ссылки убраны. Help и Credits открывают локальные документы. Optional `SecretTweak.exe` не включён и не нужен для IRQ/RSS-настроек. Сохранена совместимость с его прежним форматом CFG при наличии этого файла; его наличие не является доказательством улучшения производительности.

Названный ранее «Secret save mode» для USB IMOD отображается как **Per-device IMOD**. Это отдельная функция сохранения IMOD по типам USB-устройств, не Alternate Plan.

## Новый интерфейс

- Графитовая тема с бирюзовым акцентом, шрифт Segoe UI, компактная шапка Exovance и карточки устройств со скруглением.
- Выбранные CPU выделяются заливкой, контуром и галочкой; наведение имеет отдельное состояние. Стрелки перемещают фокус по сетке, Space/Enter меняет выбор. Сам выбор не записывает настройки.
- Enabled/On в списках выделяется акцентом, Disabled/Off — приглушённым цветом.
- Apply выделен как основное действие. У кнопок есть hover, focus, busy и disabled-состояния. Во время главной операции редактирование плана заблокировано.
- Постоянная строка состояния отличает изменение выбора, выполнение, успешное завершение и ошибку. Наличие незавершённых ошибок не позволяет отобразить успешное применение.
- Проверены контраст текста и акцента, различимость состояний и отсутствие записи настроек из события выбора. Цвет выбора означает выбор в интерфейсе; запись выполняют соответствующие Apply/Set/Auto действия.

## Исправления

- Все сдвиги при построении масок логических CPU выполняются с UInt64 до сдвига. CPU 31/32/63 больше не превращаются в ошибку или CPU 0/1.
- Распознавание масок в ручном Apply использует UInt64; старшая половина 64-битной маски больше не отбрасывается 32-битным TryParse.
- Нулевая IRQ-маска удаляет прежний override и сбрасывает policy. Ошибки записи не объявляются успехом.
- Ручной RSS использует реальные группы SMT/физических ядер, согласованный диапазон base..max и не переходит с последнего CPU на первый. Недопустимый диапазон отклоняется до записи.
- NDIS Auto/Alternate и ручной RSS используют общий механизм записи. При частичной ошибке записи RSS предпринимается восстановление прежних RSS-параметров; ошибка отката также сообщается.
- Не навязывается NUMA node 0 и не перезаписываются RSS-настройки NetAdapterCx в IRQ-only режиме. Balanced RSS не переопределяется скрытно.
- Backup сохраняет все семь относящихся к прежним RSS-изменениям ключей, их типы и отсутствие значений. Reset восстанавливает именно это состояние. Старые backup читаются, но неполный RSS-backup помечается как неполное восстановление: недостающих данных в нём не появится.
- При ошибке запрошенного backup Auto/Alternate останавливается до оптимизации.
- Ошибки основных registry-функций IRQ/MSI/policy и RSS учитываются итоговой проверкой, даже если старый вызывающий код игнорирует bool.
- Отдельное имя backup, отдельная папка и отдельный type cache. Сохранённые чужие backup/logs из оригинального комплекта сюда не включены.

## Backup и границы восстановления

Файл v2: `exovance_v2_device_settings_backup.json` в этом каталоге. Не копируйте оригинальный `device_settings_backup.json` как собственный backup. В этой версии автоматический поиск ограничен каталогом v2; выбрать другой файл можно явно через окно Reset.

Точный RSS-backup включает `*RssBaseProcNumber`, `*NumRssQueues`, `*RssBaseProcGroup`, `*RssMaxProcNumber`, `*RssMaxProcGroup`, `*MaxRssProcessors`, `*NumaNodeId`.

Это не полный системный образ и не транзакция всех настроек. Если поздний шаг Auto завершается ошибкой, ранние изменения IRQ/MSI/ReservedCpuSets могут уже быть применены. Откат внутри нового helper относится к RSS-записи конкретного адаптера. Низкоуровневые изменения NVMe/PCI/MMIO и внешние startup-скрипты не покрываются обещанием полного восстановления этим JSON. Прежние RWEverything-возможности остаются дополнительными; утилита и изменения защиты Windows не устанавливаются автоматически.

## Проверки

```powershell
pwsh -NoLogo -NoProfile -File ./tests/Test-DeviceTweakerV2.ps1
```

Команда выполняется из корня репозитория. На Windows вместо pwsh можно использовать powershell.exe.

В Linux пройдено **81 изолированная проверка логики** и **4 проверки темы/индикации**: все 64 номера CPU, смешанные маски, границы RSS, неоднородная SMT-топология, JSON-roundtrip backup, сохранение типа/отсутствия, отказ записи, откат RSS, отсутствие ложного успеха, оригинальный файл, меню и early-exit на неподходящей ОС. Реестр подменяется в памяти, устройства не изменяются.

Весь встроенный C# интерфейса успешно скомпилирован Roslyn против официальных reference assemblies .NET Framework 4.8 — 0 ошибок. Это проверка компиляции, не запуск интерфейса. В CI добавлены компиляция WinForms-типов на Windows PowerShell 5.1, проверка launcher из пути с пробелами и проверка клавиатурного выбора/отрисовки сетки CPU. Результат Windows CI нужно смотреть отдельно; локальная проверка выполнялась на Linux.

Реальное окно, маршрутизация IRQ, поддержка функций конкретными драйверами и влияние на FPS/задержку требуют проверки на целевой Windows. Исправлены подтверждённые дефекты в перечисленных блоках; заявление «все ошибки 64 тысяч строк устранены» сделать нельзя.
