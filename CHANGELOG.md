# 📝 История изменений

## v2.0.0-preview.1 — 1 ноября 2026

Большое обновление документации и удобства запуска. Статус **preview**: применение системных настроек в Windows в этой сессии не проверялось.

- Новая версия `Low-Latency-Corp-Menu_v2.cmd`; оригинальный CMD сохранён побайтно.
- Первый пункт — Preflight / About v2, а не Auto Registry Tweaks.
- Режим `/check` без применения настроек и справка `/help` / `/?`.
- Явное подтверждение `AUTO` перед пакетом и `QOL` перед отдельным QOL Optimize; Enter отменяет действие.
- Отклонение пустой загрузки драйвера и несовпадения известного размера до сохранения установщика.
- Device Tweaker и схема питания из новых коммитов репозитория подключены к меню v2. Путь `Resources` имеет приоритет; два включённых ресурса также находятся рядом с CMD.
- README с собственным баннером, графическим сравнением версий, схемой запуска и картой функций.
- Отдельное подробное сравнение, описание ограничений восстановления и внешних ресурсов.
- Автономные regression-тесты без Pester и workflow GitHub Actions для Linux / Windows PowerShell 5.1.

Поддержка Windows 11 26H2 не подтверждена и в выпуск не включена. Новых наборов «ускоряющих» значений реестра не добавлено. Прирост FPS, уменьшение задержек и совместимость всех твиков не гарантируются.
