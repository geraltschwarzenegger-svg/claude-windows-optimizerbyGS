# 📝 История изменений

## Exovance v2 — интерфейс и проверка сетевых назначений

- Увеличены интерфейс Device Tweaker, шрифт и элементы CPU; видимый бренд меню и метка NVIDIA-профиля заменены на Exovance. Параметры производительности NVIDIA не менялись.
- Исключены записи IRQ/MSI/RSS для виртуальных/неподтверждённых сетевых устройств, включая Happ Wintun; сохранена возможность восстановить их из прежнего backup.
- Закрытие окна RSS/IRQ теперь отменяет операцию. Убран принудительный GPU CPU 8/10; предпросмотр RSS согласован с фактической физической топологией и не допускает перехода через CPU 0.
- Добавлены проверки выбора устройств, отмены обработчиков Auto/Alternate, предпросмотра RSS и размера клеток CPU.


## Unreleased — Exovance Device Tweaker v2

- Добавлен отдельный `DEVICE-TWEAKER-V2`; исходный Device Tweaker сохранён без изменений и доступен из меню.
- Новый заголовок Exovance, локальные Help/Credits, Alternate Plan вместо Secret Optimization; удалены рекламные ссылки и автоматическое включение HAGS.
- Исправлены UInt64-маски, обработка пустого выбора affinity, RSS-диапазоны и SMT-топология, полный типизированный RSS-backup/restore и сообщения об ошибках основных записей.
- Добавлены отдельный launcher `/check`, ограничение на одну processor group и 81 изолированная Linux-проверка логики. Добавлены новый интерфейс с подсветкой выбора, клавиатурная навигация и 4 проверки темы/индикации. Встроенный WinForms C# компилируется против .NET Framework 4.8.


## Unreleased — NVPI Revamped

- В v2 включён официальный NVPI-R 7.3.2.0 с XML-справочниками, конфигурацией и MIT-лицензией.
- Apps и NVIDIA-шаг Auto используют `NvidiaV2.nip` и явный Merge; обычный запуск GUI не импортирует настройки.
- В пользовательском профиле сохранены все 43 значения, исправлена ошибочная декларация кодировки UTF-16 → UTF-8.
- Результат импорта остаётся предупреждением до проверки в NVPI-R: нулевой exit code не подтверждает запись настроек.
- Добавлены изолированные регрессионные тесты запуска и импорта.


## v2.0.0-preview.3 — 1 ноября 2026

- Исправлено переполнение окна в общем меню: список теперь ограничен высотой viewport, а не размером буфера прокрутки.
- Убрана частичная перерисовка по устаревшим координатам, вызывавшая повторные строки и несколько выделений после прокрутки экрана.
- Новый интерфейс: цельный кадр, цветные группы, контрастное выделение, подсказки и описание действия.
- Добавлены Home / End / PgUp / PgDn, прокрутка к выбранному пункту и перерисовка при resize. В слишком маленьком окне выбор блокируется до увеличения размера; Esc остаётся доступен.
- Совместимый renderer для классической консоли; цвета, видимость курсора, кодировка и изменённый VT mode восстанавливаются после меню.
- `/demo` и `/demo /snapshot` показывают только интерфейс и завершаются до проверки ОС, transcript и TrustedInstaller. Они не применяют настройки.
- `/demo` без интерактивного терминала возвращает код `2` и подсказывает использовать снимок, вместо ложного успешного завершения.
- Добавлены отдельные regression-тесты меню и demo. В реальном Linux PTY проверены стрелки, Home/End, уменьшение/увеличение окна и завершение demo без действий.

Изменён общий renderer меню, а не набор системных твиков. Оригинальный CMD сохранён. Отдельные специализированные экраны автозагрузки и прогресса загрузок не переписывались.

## v2.0.0-preview.2 — 1 ноября 2026

- Исправлена конфигурация оболочек CI: отдельные задания Linux / PowerShell 7 и Windows / Windows PowerShell 5.1.
- Успешный test runner явно возвращает `0`: ожидаемый код `2` дочернего `/check` на Linux больше не становится ошибкой всего CI-задания.
- Ошибки тестов публикуются в аннотациях и итогах задания.
- Проверки Windows PowerShell 5.1 и CMD `/help` / `/check` прошли в GitHub Actions. Системные твики при этом не применялись.

CMD-файлы идентичны preview.1; изменения относятся к CI, test runner и документации.

## v2.0.0-preview.1 — 1 ноября 2026

Большое обновление документации и удобства запуска. Статус **preview**: применение системных настроек в Windows в этой сессии не проверялось.

- Новая версия `Low-Latency-Corp-Menu_v2.cmd`; оригинальный CMD сохранён побайтно.
- Первый пункт — Preflight / About v2, а не Auto Registry Tweaks.
- Режим `/check` без применения настроек и справка `/help` / `/?`.
- Явное подтверждение `AUTO` перед пакетом и `QOL` перед отдельным QOL Optimize; Enter отменяет действие.
- Отклонение пустой загрузки драйвера и несовпадения известного размера до сохранения установщика.
- Device Tweaker и схема питания из новых коммитов репозитория подключены к меню v2. Путь `Resources` имеет приоритет; два включённых ресурса также находятся рядом с CMD.
- README с собственным баннером, графическим сравнением версий, схемой запуска и картой функций.
- Отдельное подробное сравнение, описание ограничений восстановления и внешних ресурсов.
- Автономные regression-тесты без Pester и workflow GitHub Actions для Linux / Windows PowerShell 5.1.

Поддержка Windows 11 26H2 не подтверждена и в выпуск не включена. Новых наборов «ускоряющих» значений реестра не добавлено. Прирост FPS, уменьшение задержек и совместимость всех твиков не гарантируются.
